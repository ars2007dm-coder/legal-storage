# Исправление типов документов — подробная инструкция

Всего 4 шага. Нужно заменить 3 файла, выполнить 2 SQL-скрипта заново
и отправить код.

---

## Шаг 1. Скачать архив и открыть его рядом со старым проектом

1. Скачайте `fsmo-lite-project.zip` (архив выше в чате)
2. Распакуйте его в отдельную папку — например, на Рабочий стол,
   получится папка `fsmo-lite` (или `fsmo-lite 4`, если Mac сам
   добавил цифру, чтобы не путать с предыдущей)

---

## Шаг 2. Заменить ровно 3 файла в вашем рабочем проекте

Не нужно заменять весь проект — только эти три файла. Из **новой**
распакованной папки скопируйте:

1. `sql/fsmo_lite_database_v5.sql`
2. `sql/fsmo_lite_database_v6_more_npa.sql`
3. `src/lib/labels.ts`

...и вставьте их в **старую** папку проекта (ту, что уже открыта в
VS Code), поверх старых файлов с такими же именами — согласитесь на
замену/перезапись, если спросит.

**Как это сделать проще всего:**
- Откройте Finder (Mac) / Проводник (Windows) в двух окнах: одно —
  новая распакованная папка, второе — ваша старая рабочая папка
  проекта
- В новой папке зайдите в `sql`, перетащите файл
  `fsmo_lite_database_v5.sql` в папку `sql` старого проекта
- То же самое для `fsmo_lite_database_v6_more_npa.sql`
- Затем зайдите в `src/lib` новой папки, перетащите `labels.ts` в
  `src/lib` старого проекта

Если Finder/Проводник спросит «Заменить файл?» — соглашайтесь.

**Проверка:** откройте в VS Code файл `sql/fsmo_lite_database_v5.sql`
— в самом начале списка НПА должна быть строка со словом
`federal_law` (а не `regulation`) рядом с «Конституция Российской
Федерации».

---

## Шаг 3. Выполнить оба SQL-скрипта в Supabase (именно в этом порядке)

### 3.1. Скрипт v5

1. Откройте **supabase.com/dashboard** → войдите → откройте ваш
   проект
2. Слева в меню найдите значок **`</>`** или подпись **SQL Editor**
3. Нажмите зелёную кнопку **+ New query** (обычно справа вверху)
4. Откроется пустое белое/тёмное поле для кода
5. Вернитесь в VS Code, откройте файл `sql/fsmo_lite_database_v5.sql`
6. Кликните внутрь текста файла, нажмите `Cmd+A` (Mac) или `Ctrl+A`
   (Windows) — выделится весь текст
7. Нажмите `Cmd+C` / `Ctrl+C` — скопируется
8. Вернитесь в Supabase, кликните в пустое поле запроса, нажмите
   `Cmd+V` / `Ctrl+V` — вставится весь скрипт
9. Нажмите кнопку **Run** (или `Cmd+Enter` / `Ctrl+Enter`)
10. Подождите — должна появиться зелёная надпись **Success** внизу.
    Если снова красная ошибка — пришлите скриншот, разберём

### 3.2. Скрипт v6

Повторите те же самые шаги 3.1, но:
- В Supabase снова нажмите **+ New query** (новый, отдельный запрос,
  не поверх предыдущего)
- В VS Code откройте файл `sql/fsmo_lite_database_v6_more_npa.sql`,
  скопируйте его целиком так же (`Cmd+A`, `Cmd+C`)
- Вставьте в новое окно запроса в Supabase, нажмите **Run**

### 3.3. Проверка результата

Ещё раз **+ New query**, вставьте:
```sql
SELECT count(*) FROM refs;
```
Нажмите **Run** — должно показать **30**.

Дополнительно можно проверить конкретно АПК:
```sql
SELECT title, official_url FROM refs WHERE abbr = 'АПК РФ';
```
Ссылка в результате должна быть
`https://www.consultant.ru/document/cons_doc_LAW_37800/`

## Шаг 4. Отправить код на GitHub (чтобы обновились подписи бейджей на сайте)

В VS Code откройте терминал (`` Ctrl+` `` / `` Cmd+` ``), наберите по
очереди:

```
git add .
```
```
git commit -m "Исправлены типы документов под реальную структуру базы"
```
```
git push
```

Vercel сам увидит изменения и пересоберёт сайт за 1-2 минуты —
проверить прогресс можно на **vercel.com** → ваш проект →
**Deployments**.

---

## Финальная проверка на сайте

1. Откройте ваш сайт (или `http://localhost:3000`, если ещё работает
   `npm run dev`)
2. Зайдите на страницу **/npa**
3. Проверьте:
   - Всего должно быть 30 документов
   - У карточек бейджи — «Кодекс», «Федеральный закон», «Постановление
     Пленума ВС» (не сырые английские слова вроде `federal_law`)
   - Кнопка «Открыть» у АПК РФ ведёт на настоящий Арбитражный
     процессуальный кодекс, а не на письмо Минфина

Если что-то не сходится — присылайте скриншот именно этого места,
разберёмся.
