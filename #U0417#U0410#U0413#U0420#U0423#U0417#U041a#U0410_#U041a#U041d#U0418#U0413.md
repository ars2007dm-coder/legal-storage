# Как загрузить свои файлы (книги) на сайт — подробно

Сайт не хранит файлы у себя — он хранит **ссылку** на файл. Поэтому
процесс в два шага: 1) выложить PDF куда-то, где у него появится
постоянная ссылка, 2) добавить эту ссылку в админку. Дальше — по
каждому шагу подробно.

Сначала — удалим 3 тестовые книги, которые видели на скриншоте
(«Комментарий к Гражданскому кодексу РФ», «Методика решения...»,
«Сборник кейсов...») — я только что добавил для этого отдельный
раздел в админке.

---

## Шаг 0. Обновить код

Как обычно — скачайте архив, замените файлы `src/app/admin/actions.ts`,
`src/app/admin/layout.tsx` и добавьте новую папку
`src/app/admin/books` (файл `page.tsx` внутри) в свой проект.

```
git add .
git commit -m "Управление книгами в админке"
git push
```

---

## Шаг 1. Удалить тестовые книги

1. Откройте `/admin/books` на вашем сайте
2. Увидите список из 3 книг
3. У каждой — кнопка **«Удалить»** справа, нажмите у всех трёх

---

## Шаг 2. Выложить PDF-файл так, чтобы у него была ссылка

Самый простой способ для новичка — **Google Диск**.

1. Откройте **drive.google.com**, войдите в свой Google-аккаунт
2. Нажмите **+ Создать** (слева вверху) → **Загрузка файла**
3. Выберите PDF-файл на компьютере из той папки, что у вас есть
4. Дождитесь загрузки — файл появится в списке
5. Кликните по нему **правой кнопкой мыши** → **Настройки доступа**
   (или иконка похожая на человечка/цепочку)
6. В открывшемся окне найдите переключатель **«Все, у кого есть
   ссылка»** (Anyone with the link) — включите его, права доступа
   оставьте **«Читатель»** (Viewer)
7. Нажмите **«Копировать ссылку»**

Ссылка будет выглядеть примерно так:
```
https://drive.google.com/file/d/1AbCдлинный-набор-символовXyZ/view?usp=sharing
```
Это и есть ваша ссылка на PDF — сохраните её, пригодится в шаге 3.

**Важно:** без включённого доступа «Все, у кого есть ссылка» файл
будет виден только вам — на сайте у других людей ссылка не откроется.

*(Аналогично можно через Яндекс.Диск: загрузить файл → «Поделиться»
→ «Скопировать ссылку» → обязательно включить доступ «Все, у кого
есть ссылка».)*

---

## Шаг 3. Добавить книгу в админку

1. Откройте `/admin/add` на сайте
2. Прокрутите до блока **«Новая книга»**
3. Заполните поля:
   - **Название** — как называется книга/пособие
   - **Автор** — ФИО автора
   - **Год** — год издания
   - **Издательство** — необязательно
   - **Тип** — выберите из списка (Учебник / Комментарий / Кейс-бук /
     Монография / Статья)
   - **Категория** — отрасль права
   - **Ссылка на PDF** — вставьте сюда ссылку из Шага 2
   - **Ссылка на обложку** — необязательно (если есть картинка обложки
     — так же выложите на Google Диск и вставьте ссылку; если нет,
     просто оставьте пустым, будет стандартная иконка книги)
4. Нажмите **«Добавить книгу»**

---

## Шаг 4. Проверка

Откройте `/books` на сайте — новая книга должна появиться в списке.
Нажмите **«Открыть PDF»** — должен открыться ваш файл в новой
вкладке (через просмотрщик Google Диска).

---

## Если книг много (не по одной руками)

Если у вас в папке много файлов и заполнять форму по одному долго —
скажите, и я сделаю **массовую загрузку**: вы присылаете мне список
(название / автор / год / ссылка на файл — например, в виде таблицы),
а я сразу пишу SQL-скрипт, который добавит их все одним запуском
через Supabase — так же, как делал с НПА.

Для этого нужно, чтобы файлы уже были выложены (шаг 2, для каждого
файла) — саму загрузку файлов в облако я сделать не могу, а вот
превратить готовый список ссылок в книги на сайте — могу, и быстро.
