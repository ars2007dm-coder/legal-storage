# Подключение SMS и всего остального — пошаговая инструкция

Здесь всё, что осталось подключить: настоящие SMS-коды (Twilio),
уведомления на почту (Resend), ИИ-проверка домашки (Anthropic),
и служебные ключи для админки. Всё разбито на отдельные части —
можно делать по одной, не обязательно всё за один раз.

Перед началом: обновите код проекта из последнего архива (замените
папку `src` и `sql` на новые), иначе кнопка «Войти» будет работать
по-старому (заглушка с кодом 1234).

## ЧАСТЬ 1. Подключить настоящие SMS-коды (Twilio)

Без этого шага кнопка «Войти» в шапке сайта работать не будет — она
теперь отправляет запрос на реальный SMS-сервис, а не принимает
фиксированный код.

### 1.1. Завести аккаунт Twilio

1. Откройте **https://www.twilio.com/try-twilio**
2. Заполните форму регистрации (имя, почта, пароль) → **Start your free trial**
3. Подтвердите почту (придёт письмо со ссылкой) и телефон (придёт SMS
   с кодом — введите на сайте)
4. Ответьте на несколько вопросов мастера настройки (можно выбрать
   любые варианты, например "Product: SMS" → "I'm a developer") —
   нажимайте **Next**, пока не попадёте в основную панель (Console)

### 1.2. Получить тестовый номер телефона

1. В левом меню Twilio Console найдите **Phone Numbers** → **Manage**
   → **Active numbers**
2. Если номера ещё нет — нажмите **Buy a number** (на пробном тарифе
   обычно даётся бесплатный номер автоматически, либо предложат
   выбрать — выберите любой с галочкой **SMS**)
3. Скопируйте этот номер (формат вида `+1XXXXXXXXXX`) — он понадобится
   позже

### 1.3. Взять Account SID и Auth Token

1. Вернитесь на главную страницу Console (логотип Twilio слева
   вверху, либо **https://console.twilio.com**)
2. На главном экране — блок **Account Info**. Там два поля:
   **Account SID** и **Auth Token** (Auth Token скрыт под точками,
   рядом иконка "глаз" — нажмите, чтобы показать)
3. Скопируйте оба значения — сохраните пока в любой текстовый файл на
   компьютере, они понадобятся через минуту

**Важно про пробный (Trial) аккаунт:** пока не оплатите Twilio,
SMS можно отправлять только на номера, которые вы заранее подтвердили
в разделе **Phone Numbers → Manage → Verified Caller IDs**. Для
тестирования на своём номере это добавьте свой номер туда (**Add a
new Caller ID**, введите номер, придёт код подтверждения). Чтобы
пускать всех подряд учеников — нужно будет пополнить баланс Twilio
(обычно от 20$, дальше платите по факту отправленных SMS).

### 1.4. Подключить Twilio в Supabase

1. Откройте **https://supabase.com/dashboard**, войдите, откройте
   проект **legal-storage**
2. В левом меню найдите значок замка/ключа — **Authentication**
3. Внутри слева — **Sign In / Providers** (или просто **Providers**)
4. Найдите в списке **Phone** → нажмите, чтобы раскрыть настройки
5. Включите переключатель **Enable Sign in with Phone**
6. В поле **SMS Provider** выберите **Twilio** из выпадающего списка
7. Заполните появившиеся поля:
   - **Twilio Account SID** — вставьте то, что скопировали в шаге 1.3
   - **Twilio Auth Token** — то же самое
   - **Twilio Message Service SID** ИЛИ **Twilio Phone Number** —
     обычно проще указать номер телефона из шага 1.2 (в поле "Twilio
     Phone Number" впишите его в формате `+1XXXXXXXXXX`)
8. Нажмите **Save** внизу

### 1.5. Проверка

1. На вашем сайте (после того как обновите код — см. Часть 5)
   нажмите «Войти» в шапке
2. Введите свой (подтверждённый в Twilio, если аккаунт ещё Trial)
   номер телефона, поставьте галочку согласия, нажмите «Получить код»
3. На телефон должно прийти настоящее SMS с 6-значным кодом
4. Введите код на сайте → должны войти

Если пришла ошибка — скриньте и пришлите мне, разберём.

## ЧАСТЬ 2. Уведомления на почту о заявках (Resend)

Нужно, чтобы вам приходило письмо, когда ученик подаёт заявку на
доступ к ДЗ через `/join`.

### 2.1. Завести аккаунт

1. Откройте **https://resend.com**
2. Нажмите **Sign Up**, зарегистрируйтесь (можно через Google-аккаунт
   — кнопка **Continue with Google** — это быстрее всего)

### 2.2. Получить API-ключ

1. После входа откроется панель (Dashboard). Слева найдите **API Keys**
2. Нажмите **Create API Key**
3. Введите любое имя (например `fsmo-lite`), права оставьте по
   умолчанию (**Sending access**), нажмите **Add**
4. Появится ключ вида `re_xxxxxxxxxxxx` — **скопируйте его сразу**,
   второй раз он не покажется (если забудете — просто создайте новый)

### 2.3. Про адрес отправителя

Без подтверждения собственного домена Resend разрешает отправлять
письма только на тот email, на который вы зарегистрировались в
Resend — этого достаточно, чтобы получать уведомления себе. Ничего
дополнительно настраивать не нужно.

## ЧАСТЬ 3. ИИ-проверка домашних заданий (Anthropic)

### 3.1. Завести аккаунт

1. Откройте **https://console.anthropic.com**
2. Зарегистрируйтесь (email + пароль, либо через Google)

### 3.2. Пополнить баланс

1. В левом меню найдите **Billing** (или **Plans & Billing**)
2. Нажмите **Add to credit balance** (или похожую кнопку "Пополнить")
3. Введите сумму (для теста хватит 5$), привяжите карту, оплатите

Без этого шага ключ создать можно, но запросы будут выдавать ошибку
нехватки баланса.

### 3.3. Получить API-ключ

1. В левом меню — **API Keys**
2. Нажмите **Create Key**
3. Введите имя (например `fsmo-lite`), нажмите **Create Key**
4. Скопируйте ключ вида `sk-ant-...` сразу — второй раз не покажется

## ЧАСТЬ 4. Служебные ключи Supabase и пароль админки

### 4.1. Service Role Key

1. В Supabase (**https://supabase.com/dashboard** → проект
   **legal-storage**)
2. Слева — значок шестерёнки **Project Settings** (внизу списка)
3. Внутри — **API**
4. Раздел **Project API keys** → найдите строку **service_role**
   (она подписана как **secret**, рядом кнопка "глаз", чтобы
   показать/скрыть)
5. Нажмите на "глаз", затем скопируйте значение

**Никогда никому не показывайте и не публикуйте этот ключ** — он даёт
полный доступ к базе данных в обход всех ограничений.

### 4.2. Пароль администратора

Просто придумайте свой пароль для входа в раздел `/admin` вашего
сайта — любой, который легко запомнить, но нежелательно совсем
простой (например `admin123`). Никуда вводить заранее не нужно —
впишете его в `.env.local` в следующей части.

## ЧАСТЬ 5. Собрать всё в .env.local и Vercel

### 5.1. Обновить .env.local на компьютере

1. Откройте в VS Code файл `.env.local` (в корне проекта)
2. Допишите (или обновите, если строки уже есть) — подставьте свои
   значения из частей 1–4:

```
NEXT_PUBLIC_SUPABASE_URL=https://dptjwqsoisqlbaiolvmx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<уже был указан ранее>

SUPABASE_SERVICE_ROLE_KEY=<из части 4.1>
ADMIN_PASSWORD=<из части 4.2, придумали сами>

RESEND_API_KEY=<из части 2.2>
ADMIN_EMAIL=<ваша почта — та же, что регистрировали в Resend>

ANTHROPIC_API_KEY=<из части 3.3>
```

3. Сохраните (`Cmd+S`)
4. В терминале: `Ctrl+C`, затем заново `npm run dev`
5. Проверьте на `http://localhost:3000` — всё должно заработать
   локально (SMS настоящие придут только если Twilio настроен и номер
   подтверждён — см. часть 1.3)

### 5.2. Обновить те же переменные в Vercel

1. Откройте **https://vercel.com**, зайдите в проект **legal-storage**
2. Сверху — **Settings**
3. Слева — **Environment Variables**
4. Для каждой из пяти НОВЫХ переменных (`SUPABASE_SERVICE_ROLE_KEY`,
   `ADMIN_PASSWORD`, `RESEND_API_KEY`, `ADMIN_EMAIL`,
   `ANTHROPIC_API_KEY`):
   - Нажмите **Add New**
   - **Key** — впишите точное имя переменной (как в списке выше)
   - **Value** — вставьте своё значение
   - Environment — оставьте отмеченными все три галочки (Production,
     Preview, Development)
   - Нажмите **Save**
5. После того как добавили все пять — зайдите на вкладку
   **Deployments**, у самого верхнего деплоя нажмите `⋯` (три точки)
   → **Redeploy** → подтвердите — иначе новые переменные не применятся
   к уже собранному сайту

### 5.3. Отправить обновлённый код (модалку входа) на GitHub

Не забудьте — это отдельно от переменных окружения, нужно тоже сделать:

```
git add .
git commit -m "Подключение настоящего SMS-входа"
git push
```

## Итоговый чек-лист проверки

- [ ] `/` — сайт открывается, ничего не сломалось
- [ ] Кнопка «Войти» → ввод номера → приходит настоящее SMS (не 1234)
- [ ] После ввода кода — вход происходит, кнопка меняется/сайт
      перезагружается без ошибок
- [ ] `/join` → заявка → на вашу почту приходит письмо
- [ ] `/admin` → просит пароль → пускает по вашему `ADMIN_PASSWORD`
- [ ] `/admin/requests` → одобряете заявку → код появляется в списке
- [ ] `/verify` → вводите тот же номер и код → появляется вкладка «ДЗ»
- [ ] `/homework` → отвечаете на задание → приходит разбор от ИИ с
      оценкой (не ошибка про отсутствующий ключ)

Если что-то из списка не проходит — пришлите скриншот именно этого
шага, разберёмся по одному пункту, как обычно.
